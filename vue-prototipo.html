Requisito 1 — Título Dinâmico

📝 Título Reativo

No Vue.js, a diretiva v-model vincula o campo de texto ao dado titulo em tempo real — sem tocar no DOM manualmente. Aqui replicamos esse comportamento com JavaScript.

Título: Desafios da Formação...
Caracteres: 48
// Vue.js — dado reativo (Composition API)
const titulo = ref('Desafios da Formação...')

// Template — vinculação bidirecional automática
<input v-model="titulo" />
<h1>{{ titulo }}</h1> <!-- atualiza sozinho -->
Requisito 2 — Botão Interativo

👆 Botão com Evento de Clique

No Vue.js, @click substitui o addEventListener — mais declarativo e limpo. O dado cliques é reativo: qualquer mudança atualiza o template automaticamente.

0
Interaja com os botões para ver a reatividade em ação.
// Vue.js — dado reativo
const cliques = ref(0)

// Template — diretiva @click
<button @click="cliques++">Clique</button>
<p>{{ cliques }} cliques</p>

// Renderização condicional
<span v-if="cliques >= 20">🔥 Máximo!</span>
