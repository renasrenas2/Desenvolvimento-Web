🛡️ Aula 18 — Análise de Vulnerabilidade XSS e Resolução

❌ Caminho Vulnerável

Usar innerHTML para exibir o texto do usuário executa qualquer script injetado — por exemplo, <script>alert('XSS')</script> seria interpretado e executado pelo browser, comprometendo todos os usuários que visualizassem o feedback.

✅ Caminho Seguro (implementado)

Este sistema usa textContent para inserir o texto no DOM. Qualquer tentativa de injeção de script é tratada como texto puro e inofensivo. No backend, o pacote helmet adiciona cabeçalhos HTTP de segurança (Content-Security-Policy, X-Frame-Options, etc.).
